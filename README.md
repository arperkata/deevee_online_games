# deevee_online_games

158 quick, addictive brain games for kids and grown-ups. 130 of them have 2-player (with player names) and vs-Computer modes. Single-file HTML, no installs, works on phone, tablet, laptop and PC. Every game has a 3D dragon buddy (`mascot.js`).

**Play online:** https://arperkata.github.io/deevee_online_games/

Open `index.html` to browse all games (search + category filters). The play-money games sit in their own tab (ages 13+).

- `privacy.html` - privacy policy (fill in your name/email before using your own domain)
- `ads-config.js` / `ads.js` - ads are **off** by default; see the comments in `ads-config.js`
- `manifest.webmanifest` + `sw.js` - lets people install the site as an app
- `tools/make-sitemap.js` - regenerate `sitemap.xml` / `robots.txt` for your own domain
- `PORTALS.md` - how to submit the best games to game portals
