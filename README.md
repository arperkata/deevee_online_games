# deevee_online_games

158 quick, addictive brain games for kids and grown-ups. 130 of them have 2-player (with player names) and vs-Computer modes. Single-file HTML, no installs, works on phone, tablet, laptop and PC.

**Play online:** https://arperkata.github.io/deevee_online_games/

Open `index.html` to browse all games (search + category filters). Each game is a standalone `.html` file.
